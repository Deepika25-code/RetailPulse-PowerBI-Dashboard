# RetailPulse Power BI Dashboard

## Project Overview

RetailPulse is an interactive Power BI dashboard project developed using retail sales data to generate business insights and support data-driven decision making.

## Dashboard Features

* Executive Summary Dashboard
* Sales Trend Analysis
* Product Performance Dashboard
* Customer Analytics Dashboard
* Region/Country Sales Dashboard
* Monthly & Seasonal Sales Dashboard
* Customer Behaviour Dashboard
* Profit & Revenue Analysis
* Inventory Risk Dashboard
* Order & Transaction Dashboard
* Advanced Analytics Dashboard
* Interactive Filter Dashboard

## Tools & Technologies Used

* Power BI
* DAX
* Data Visualization
* Business Intelligence

## Features

* KPI Cards
* Forecast Analytics
* Interactive Filtering
* AI Visuals
* Synced Slicers
* Revenue Analysis
* Customer Insights
* Regional Sales Analysis

## Dataset

Retail sales transactional dataset used for analytics and dashboard development.
